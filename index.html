🏛️

Arquitectura de Software & Clean Arch

Diseño de sistemas estructurados en 4 capas estrictas (Domain, Application, Infrastructure, Presentation). Aplicación de Domain-Driven Design (DDD), principios SOLID y patrones de diseño para código mantenible a largo plazo.

  • Separación estricta de responsabilidades sin dependencias en el Dominio.
  • Entidades ricas con máquinas de estado y Value Objects inmutables.
  • Manejo de errores profesional con Result Pattern y middleware global RFC 7807.
Clean Architecture DDD SOLID CQRS / MediatR

Desarrollo Backend (.NET & APIs RESTful)

Construcción de servicios backend robustos y seguros con ASP.NET Core Web API (.NET 8, 9 y 10). Persistencia eficiente con Entity Framework Core sobre PostgreSQL, SQL Server o MySQL.

  • Autenticación y autorización basada en roles (RBAC) con ASP.NET Identity y JWT.
  • Consultas LINQ optimizadas con AsNoTracking() y migraciones Code-First.
  • Generación de reportes PDF con QuestPDF y exportaciones Excel con EPPlus.
ASP.NET Core Web API C# Moderno EF Core PostgreSQL

Desarrollo Web Frontend (React & Angular)

Creación de aplicaciones web SPA reactivas, responsivas y fuertemente tipadas en TypeScript. Enfoque mobile-first y componentes modulares con Tailwind CSS y Bootstrap.

  • Aplicaciones con React (Hooks, Vite) y Angular (Signals, RxJS Observables).
  • Consumo de APIs RESTful mediante servicios HTTP tipados con tipado estricto.
  • Diseño adaptable, limpio, accesible y centrado en la experiencia de usuario (UX).
React + TS Angular Tailwind CSS TypeScript

DevOps, Contenedores & Cloud

Contenerización completa con Docker Compose para garantizar paridad entre desarrollo y producción. Despliegues en la nube con Microsoft Azure y pipelines de integración continua.

  • Configuración de entornos multicontenedor (API + Base de Datos + Client).
  • Servicios en Microsoft Azure (App Services, Key Vault y bases de datos cloud).
  • Automatización con GitHub Actions y documentación OpenAPI interactiva con Scalar.
Docker Compose Microsoft Azure GitHub Actions Scalar
